# XML-JSON-Lab4
## Project Overview
This repository contains the source code for **Lab 4**. The primary objective of this project is to create and validate **XML** and **JSON** documents. Additionally, it demonstrates how to display structured data—specifically a book catalogue and user profiles—using **HTML**, **JavaScript**, and the **Fetch API**.
## File Structure
The project consists of the following key files:
  index.html: The main entry point for the application.
  json.html: A dedicated page for rendering and displaying JSON data.
  book.xml: An XML file containing the book catalogue data structure.
  userProfiles.json: A JSON file storing user profile information.

## How to Run
1. Clone or download this repository to your local machine.
2. Open index.html in your web browser to view the main interface.
> Note: Since this project uses the Fetch API to load local data files (book.xml and userProfiles.json), you may encounter Cross-Origin Resource Sharing (CORS) errors if you simply double-click the HTML file. It is recommended to run the project using a local development server (such as the "Live Server" extension in VS Code) to ensure the data loads correctly.
